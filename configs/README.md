# Parameterized Config Examples

- `evaluation.example.json`
- `loco_four_class.example.json`
- `rars_grid.example.json`
- `training.example.json`
- `inference.example.json`
- `rl_lhm.example.json`

Deployment locations are placeholders (environment-style or /path/to).
`rars_grid.example.json` is the complete private four-dimensional joint-grid
configuration; the public cohort uses six axes automatically. The examples bind
the promoted algorithm interfaces; they do not claim that the unbundled
distributed VeRL/checkpoint/GPU runtime has been integration-tested.
